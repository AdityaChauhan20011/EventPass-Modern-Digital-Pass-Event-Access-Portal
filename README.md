# EventPass — Modern Digital Pass & Event Access Portal

A modern, photorealistic static web application for discovering premier tech summits, masterclasses, and workshops, and generating verifiable digital lanyard badges with instant offline QR access, custom tiers, and calendar synchronization.

## ✨ Features

- **Luxury Soft Light UI**: Frosted glassmorphism, floating ambient glow orbs, and soft pastel radial backdrops.
- **Realistic Digital Pass & Ticket Stubs**:
  - Photorealistic lanyard punch hole & clip header
  - Animated holographic foil shimmer
  - Verifiable QR code generation & SVG barcode
  - Perforated tear-off cutout styling
- **Multi-Tier RSVP System**: Standard, VIP All-Access, and Student/Dev tiers with custom avatar selection.
- **Organizer Mode**: Create, publish, and manage custom events with instant local storage persistence.
- **Export & Integration**:
  - 📥 **Download Badge**: Render and download high-resolution passes as PNG images (HTML5 Canvas).
  - 📅 **Add to Calendar**: Export standard `.ics` calendar events.
  - 🖨️ **Print Ready**: Specialized `@media print` layout optimized for physical badge printing.
- **100% Static & Offline**: No backend or server dependencies required. Runs directly in any modern browser.

## 🚀 Getting Started

Simply open `index.html` in your favorite web browser:

```bash
# Clone the repository
git clone https://github.com/914learner/EventPass-Modern-Digital-Pass-Event-Access-Portal.git

# Navigate to project folder
cd EventPass-Modern-Digital-Pass-Event-Access-Portal

# Open index.html in default browser (Windows)
start index.html
```
